## What we run

EdgeConneX operates 90+ data centers across 20+ countries, built for customers ranging from single-market edge deployments to multi-hundred-megawatt AI-ready campuses. Behind that footprint is a multi-cloud platform spanning Azure, AWS, and GCP, run on Terraform-first infrastructure as code and GitHub Actions CI/CD.

## What this org is

This is where EdgeConneX's Cloud Services & Hybrid IT and DevOps teams build and publish engineering work: infrastructure modules, automation, and internal platform tooling, including an in-house MCP server framework used for governance and AI-assisted operations across our cloud environments.
